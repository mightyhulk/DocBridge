# Third-party licences and data sources

Vitalis AI is built from free and open-source parts. This list is for orientation. **Licences change, so confirm the current terms on each
project's page before you redistribute or use anything commercially.** Entries marked ⚠ need your attention.

The project's own source code does not yet declare a licence; the owner should choose one and add it here.

## Models

| Model | Used for | Licence / terms |
|---|---|---|
| MedGemma-4B-it (`unsloth/medgemma-4b-it-GGUF`) | Patient Consult explanations | ⚠ Google's Health AI Developer Foundations terms (MedGemma). Research and development use; not a medical device. Read the terms before any clinical or commercial use. |
| Qwen2.5-3B-Instruct | Clinical Assistant answers (default) | ⚠ The 3B model is published under the Qwen Research licence (non-commercial). The 7B model is Apache-2.0. Check the model card. Swap with `HVA_LLM_MODEL`. |
| BAAI/bge-small-en-v1.5 | Embeddings for the clinical knowledge base | MIT |
| sentence-transformers/all-MiniLM-L6-v2 | Embeddings for the doctor-patient case index | Apache-2.0 |
| Whisper `base.en` via faster-whisper | Speech-to-text | MIT |
| Piper voice `en_US-amy-medium` | Text-to-speech | ⚠ See the voice's model card for the dataset terms. |

## Data and online services

| Source | Used for | Terms |
|---|---|---|
| ChatDoctor-HealthCareMagic-100k (`lavita`) | Doctor-patient case index | ⚠ No licence is declared on the dataset page at the time of writing. Treat as research/demo data. Rows are not redistributed in this repository. |
| AI-Medical-Chatbot (`ruslanmv`) | Doctor-patient case index | ⚠ Same as above. |
| MedlinePlus (US National Library of Medicine) | Reference answers and links | US government work; follow NLM's attribution and usage guidance. |
| openFDA drug labels | Drug dosing and label text | Public domain (CC0); follow openFDA's terms and rate limits. |
| Wikipedia abstracts (via DuckDuckGo instant answers) | General references | CC BY-SA 4.0. Requires attribution; the source is shown with every answer. |
| Web search (DuckDuckGo via `ddgs`) and the pages it finds (Mayo Clinic, NHS, CDC, WHO, Cleveland Clinic and others) | Sourced answers with links | Each page remains the copyright of its owner. The app reads short excerpts and always shows the link. Respect each site's terms. |
| OpenStreetMap data, Nominatim and Overpass | Nearby doctors and hospitals; place search | ODbL. Display "© OpenStreetMap contributors". Public endpoints have usage policies: send an identifying User-Agent and keep volume low. |
| Google Identity (OAuth 2.0) | Patient sign-in | Google API Terms of Service. |
| Synthetic patient records | Demo data | Generated by `src/backend/scripts/generate_patients.py`; fictional. |

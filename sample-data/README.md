# sample-data

Small, **synthetic** files for trying the system and reading its data shapes. Nothing here is real patient data.

| File | What it is |
|---|---|
| `patients.sample.json` | 5 synthetic patients (allergy, kidney disease, anticoagulant, diabetes, plain) with encounters. The full set of 200,000 is generated by `src/backend/scripts/generate_patients.py` into `data/`. |
| `doctor-patient-cases.sample.json` | Hand-written examples of the doctor-patient case shape used by the Patient Consult retrieval index. |
| `consultation-transcript.sample.md` | An example consultation, end to end. |

Try it: in the Clinical Assistant tab search for one of the sample patient names, or ask "Can I prescribe ibuprofen for this patient?".
